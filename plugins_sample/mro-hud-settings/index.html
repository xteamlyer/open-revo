Frame rate readings

— · —

--Frametime ms

--Window average
--Sampled frames

1% Low preferably uses RTSS's per-frame frametime array: one sample per frame, sorting every frame in the window by frametime in descending order, averaging the worst 1% of frames, and converting that back to a frame rate - the same accuracy class as NVIDIA FrameView / PresentMon. If this RTSS version does not have that array, it falls back to an approximate "8ms polled frame counter" sample.

A full-screen game was detected: under exclusive fullscreen no window can be drawn on top of it, so the HUD will inevitably be hidden. Please switch the game's display settings to "Borderless Windowed".

How to read these numbers

FPS The average frame rate over the last second reported by RTSS, reflecting how fast the game runs right now.
1% Low Takes the worst 1% of frames in the window and averages them into a frame rate. The bigger the gap between it and FPS, the more noticeable the stutter; averaging 120 fps but a 1% Low of only 40 feels like "constant stuttering" in practice.
Prerequisite RTSS must be running, and the game must have been started after RTSS launched (RTSS only hooks processes at creation time). Switching to the desktop does not clear the statistics; the agent keeps using the game entry that is still producing frames.

Background style

Dark = a dark gray-blue gradient; Glass = a dark gray-blue base with a cool white thin edge; Flat = a very dark gray. For these three, "Background opacity" controls how strong the card background is (0% means the game shows through completely), while "Text opacity" only affects the text; the two do not interfere with each other. "Transparent" removes the background layer entirely, leaving only the text floating over the game.
